# CK2 ID SIZE
# The CK2 2.7.1 notes document a fixed crash involving IDs at or above one
# billion. The AGOT-Fixed-ID mod authors reported a separate numeric trigger
# issue near one million on CK2 2.8. These reports establish historical
# compatibility issues. We have no benchmark showing a speed gain from
# smaller IDs, or a confirmed current engine ceiling. The compact range
# also avoids the lower IDs still referenced by inherited events and DLC
# character metadata.
#
